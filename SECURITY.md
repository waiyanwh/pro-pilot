# Reporting vulnerabilities

Do not post credentials, cluster data or an exploit against a live deployment in
a public issue. Use GitHub's private vulnerability reporting if enabled; otherwise
contact the repository owner through the contact options on their GitHub profile.
Include the affected version, minimal synthetic reproduction, observed impact and
any proposed fix.

This initial source release has no formal support window or response-time guarantee.
Deployments must use dedicated read-only identities and review provider data handling.
See docs/security.md for trust boundaries and known limitations.
